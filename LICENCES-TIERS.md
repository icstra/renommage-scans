# Logiciels libres inclus dans Renommage de scans

Renommage de scans contient les logiciels libres suivants, avec leurs dépendances. Chacun reste soumis à sa propre licence. Le code source de chaque composant est disponible à l'adresse indiquée.

| Composant | Rôle dans l'application | Licence | Code source |
|---|---|---|---|
| Poppler (pdftoppm, pdfinfo…) — 26.10.0 sur Mac, 26.09.0 sur Windows | Conversion des pages PDF en images | GNU GPL v2 ou ultérieure | https://poppler.freedesktop.org/ — compilation Windows : https://github.com/oschwartz10612/poppler-windows |
| Tesseract OCR — 5.5.3 sur Mac, 5.4.0 sur Windows | Lecture du texte | Apache 2.0 | https://github.com/tesseract-ocr/tesseract — compilation Windows : https://github.com/UB-Mannheim/tesseract |
| Données de langue Tesseract (fra, deu, ita, eng, osd) | Dictionnaires de lecture | Apache 2.0 | https://github.com/tesseract-ocr/tessdata_fast |
| Python 3 | Langage de l'application | Python Software Foundation License | https://www.python.org/ |
| OpenCV (opencv-python) | Traitement d'images, détection de visage | Apache 2.0 | https://github.com/opencv/opencv-python |
| Pillow | Images | MIT-CMU (HPND) | https://github.com/python-pillow/Pillow |
| NumPy | Calcul | BSD 3 clauses | https://github.com/numpy/numpy |
| pytesseract | Liaison avec Tesseract | Apache 2.0 | https://github.com/madmaze/pytesseract |
| pdf2image | Liaison avec Poppler | MIT | https://github.com/Belval/pdf2image |
| pypdf | Lecture et écriture de PDF | BSD 3 clauses | https://github.com/py-pdf/pypdf |
| python-dateutil | Dates | Apache 2.0 / BSD 3 clauses | https://github.com/dateutil/dateutil |
