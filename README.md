# Renommage de scans

Application pour Mac et Windows qui **reconnaît automatiquement les pièces d'identité et documents administratifs scannés** (carte d'identité, permis de séjour, passeport, permis de conduire, permis d'élève, carte grise, attestation d'assurance, extrait du casier judiciaire), **les renomme** selon des modèles de noms et les range par catégorie.

## Télécharger

| Ordinateur | Fichier |
|---|---|
| **Mac** (macOS 12 ou plus récent) | [RenommageScans-macOS.dmg](https://github.com/icstra/renommage-scans/releases/latest/download/RenommageScans-macOS.dmg) |
| **Windows** (10 ou 11) | [RenommageScans-Windows.zip](https://github.com/icstra/renommage-scans/releases/latest/download/RenommageScans-Windows.zip) |

Ces liens téléchargent toujours la dernière version. Aucun compte n'est nécessaire.
Les nouveautés de chaque version sont décrites sur la page [Versions](https://github.com/icstra/renommage-scans/releases).

## Installer sur Mac

1. Ouvrez `RenommageScans-macOS.dmg`.
2. Glissez **RenommageScans** sur le raccourci **Applications**. Pour une mise à jour, acceptez de remplacer l'ancienne version.
3. Ouvrez l'application depuis le dossier Applications.

**Au premier lancement**, macOS indique que l'application ne peut pas être vérifiée, parce qu'elle n'est pas signée par Apple. Pour l'autoriser :

1. Fermez le message.
2. Ouvrez **Réglages Système** → **Confidentialité et sécurité**.
3. Tout en bas, à côté de « RenommageScans a été bloqué », cliquez sur **Ouvrir quand même**, puis confirmez avec votre mot de passe.

Sur les versions plus anciennes de macOS, un clic droit sur l'application → **Ouvrir** suffit. Cette autorisation n'est à donner qu'une seule fois.

## Installer sur Windows

1. Faites un clic droit sur `RenommageScans-Windows.zip` → **Extraire tout…**. Ne lancez pas l'application depuis le fichier .zip sans l'avoir extrait.
2. Dans le dossier extrait, ouvrez le dossier `RenommageScans` et lancez **RenommageScans.exe**.
3. Si Windows affiche « Windows a protégé votre ordinateur », cliquez sur **Informations complémentaires**, puis sur **Exécuter quand même**.

## Utilisation

Le manuel d'utilisation est intégré à l'application : menu **Aide → Manuel d'utilisation** (sur Mac).

## Confidentialité

L'application fonctionne **entièrement sur votre ordinateur**. Les documents scannés ne sont envoyés nulle part : la lecture des documents, la reconnaissance et le renommage se font localement.
